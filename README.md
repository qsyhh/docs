# 该Docs由VuePress搭建

[查看VuePress文档](https://theme-hope.vuejs.press/zh)

# 本地运行

最低要求 [NodeJs 16.x](https://nodejs.cn/)

```
git clone --depth 1 https://github.com/qsyhh/docs && cd docs
pnpm i
pnpm docs:dev
```
